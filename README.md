# 新睿等级分

查看桥牌牌手的等级分、排名与历史轨迹，回顾近 30 日计分对局。

用户名或历史昵称完整符合 11 位大陆手机号格式时，中间四位显示为 `****`，保留前三位和后四位；其他昵称保持原样。公开数据文件也采用同样的脱敏规则。

## 可以查看什么

- **排行榜**：按等级分排序，支持昵称搜索、成熟／暂定状态筛选、近 30 日活跃筛选，以及翻页和跳页。
- **上分榜与下分榜**：查看昨日、近 7 日或近 30 日的等级分净变化，每榜最多展示 30 人。
- **个人概览**：查看当前等级分、近期变化、历史最高分、有效场数与副数、近 30 日场均 VP，以及成熟牌手的全站排名与分位数；可复制个人链接分享。
- **等级分曲线**：查看已收录的全部历史或近 30／7 日曲线。背景按等级分区间划分，纵轴随查看范围调整；悬停查看日期、等级分、当日变动与表现分，拖动框选横轴可放大，再点击“恢复范围”返回。
- **近 30 日计分对局**：查看赛事、轮次、桌台、对手、比分和副数，支持按赛事或对手筛选。对手姓名旁展示该对局计分前的等级分。
- **数据概览与规则**：查看牌手数量、近期对局统计、成熟牌手中位等级分，以及数据覆盖范围和更新时间。

## 等级分与排名口径

### 暂定与成熟

牌手最初为暂定状态。累计至少 **400 副有效牌**，且最后有效计分时 **RD ≤ 225**，表示达到当前可信度门槛，成为成熟牌手；RD 表示等级分的不确定度。

成熟状态只在有有效对局的计分日重算。长期未参赛会使 RD 回升，恢复参赛后若日末 RD 仍高于 225，可重新变为暂定；没有新有效对局时保留最后计分状态。

成熟牌手的用户名颜色对应等级分区间。暂定牌手使用黑色用户名，可以出现在排行榜中，但不赋予名次：榜单显示“—”，个人页显示“#-”，不计算分位数。

排名与分位数以全站成熟牌手为统计范围。筛选排行榜后，显示的仍是全站名次。

### 起步阶段与涨跌榜

新牌手的等级分从 0 起步，前六场有效计分对局逐步释放初始分数。完成六场与转为成熟是两个独立条件。

个人概览和历史曲线保留起步阶段的等级分变化。上分榜与下分榜采用相同口径：**只累计在当日开始前已完成六场有效计分对局的日期**。即使当天完成第六场，该日也整日排除，从下一计分日开始累计。两榜均只展示符合筛选条件的成熟牌手。

### 对局与每日结算

仅计入已确认由新睿主办的官方赛事中，在发布截止时间之前结束、已完整校验的轮次。赛事尚未全部结束时，已完成的完整轮次也可以计入。轮空、无效账号、弃权和异常无效比分不进入计分。

同一天的对局在日末统一结算。对手的等级分与用户名颜色采用该场计分前的状态，同一天共用日初状态。网页比分采用计分使用的归一化 **20 VP**；近 30 日场均 VP 是这些有效对局 VP 的算术平均。团体赛的个人配对以“第 X 台”展示。

所有日期与统计周期均按北京时间自然日计算。网页会标明本次数据的排他截止时间：只有早于该时间的已完成轮次才会纳入。

历史曲线与最高分使用当前算法重算的结果；比分修订或算法调整可能改变历史。当前覆盖日期、数据截止时间、最后成功发布时间和算法版本以网页“等级分规则”页为准。
